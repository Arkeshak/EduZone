## 💡 Key Topics Covered

### Authentication System
- Registration (frontend → backend → email)
- Login (credentials → tokens)
- Token refresh (automatic background refresh)
- JWT tokens (what they are, why we use them)
- Password hashing (security)
- Email verification

### Welfare Request System
- Teacher submission (form → backend → database)
- Principal approval (status change → notification)
- ZEO publishing (visibility to donors)
- Donor funding (multiple donations to one request)
- Automatic status changes (when fully funded)
- Fund transfer (to school bank account)

### Data Organization
- User table (all users)
- Donor, Teacher, Principal tables (role-specific)
- School table (institution)
- Student table (beneficiaries)
- WelfareRequest table (core feature)
- Donation table (contributions)
- Transfer table (fund movements)
- PasswordReset, Notification tables (auxiliary)

### Code Navigation
- File structure overview
- How to find features
- How to trace code flow
- Debugging techniques
- Code patterns
